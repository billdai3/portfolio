# C2C 數位資產交易 App
提供安全、即時的場外交易

## 專案簡介與目標
這是一款專注於場外交易的數位資產平台。用戶將虛擬幣轉入平台後，能夠支付給合作商家，或與其他用戶進行買賣，平台扮演第三方中介角色，協助交易流程的順暢與安全。

### 專案目標
- 安全透明的資金流動：易懂的介面提示，友善的操作流程，協助用戶做出判斷，讓用戶能安心將資金轉入平台，提升使用的滿意度。
- 引導明確的交易流程：直觀的訂單明細，一致的用詞跟術語，讓用戶在交易過程中，能有效地掃視、確認資訊，促進訂單的完成率。

### 成果摘要
將複雜的 C2C 交易流程轉化為直覺的體驗，從 0 到 1 建立了具備擴充性的 Design System，提升團隊的協作效率並降低溝通成本，最後推動專案順利上線。

## 專案影響與反思
### 效果與影響
- 設計資源的高效利用：開發過程中，我建立了完整的 Design System，從顏色的定義、到不同狀態的元件設計，都整理成規範，讓工程師在實作時能快速套用，迭代時也能快速調整，提升開發效率。
- 業務邏輯的有效傳達：資產系統及 C2C 業務的細節繁雜，我整理了許多文件，包括繪製業務流程圖、邊緣案例、撰寫訂單細節、錯誤訊息、文案等，幫助 PM 與工程師梳理不同情境，減少後續補漏洞的時間成本。
- 推動產品的順利落地：在時程內順利交付了 C 端到 B 端的完整設計，幫助業主建立穩固的產品基礎，後續也順利達成預期的業務目標及收益，獲得業主的肯定。

### 專案反思與學習
- Design system 的架構：製作過程中，參考了國外大廠的設計方式，學習並整合出適合團隊內部使用的架構，包括 Design tokens 的層次 (Primitive → Semantic) 與套用，元件的結構與命名，將設計稿整理得更清楚，也提升了開發的效率。
- 文件的書寫與傳達方式：為了避免過往碰過的地雷再次發生，我積極參考了網路上不同文件（像是錯誤訊息、通知文案等）的整理方式，也透過 AI 的協助，收斂了許多文案上的選擇，並且跟工程師討論資料上的實作細節，讓我更理解實作的邏輯跟限制。
