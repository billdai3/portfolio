# MDX Style Guide

Lab MDX 元素對照速查。內文繼承 `font-body`（GlowSans 單字型）；`h1` 使用 `type-page-title`，`h2` / `h3` 使用 `font-display` 混排（Montserrat Alternates + GlowSans）。`font-extrabold` 時混排層西文為 Montserrat 700、中文為 GlowSans 800。頁面 `<h1>` 由 MDX 的 `#` 提供；正式 Lab MDX 應只寫一個 `#`。本 styleguide 在 h1 示範區可能刻意出現多個 `#`。

## Headings（標題）

MDX 標題層級：`#` 頁面標題（`type-page-title`）→ `##` 章節標題（`font-display` 1.5rem）→ `###` 子章節（`font-display` 1rem）。`##` 與站內區塊用的 `type-section-title`（1.75rem，見 HomePage）是不同樣式，請勿混用名稱。`####`（`h4`）目前未 map，見下方 Gaps。捲至 `## Paragraphs` 可見連續 `##` 的 `not-first:mt-6` 間距。

## Paragraphs（段落）

一般段落用於正文內容。內文走 `font-body`（GlowSans 單字型），英文使用 GlowSans 內建拉丁字母。

This is a sample paragraph. It uses secondary text color and `leading-[1.75]` line height for comfortable reading.

## Text formatting（文字格式）

行內文字格式對照。`strong` 與 `em` 目前使用瀏覽器預設樣式，尚未在 `labMdxComponents` 自訂。

**Italic（`em`）刻意不處理：** 本站以中文內容為主，排版上不依賴斜體強調；GlowSans 僅載入 `font-style: normal` 字重，且 `body` 設有 `font-synthesis: none`，即使 MDX 寫 `*italic*` 渲染為 `<em>` 也幾乎看不出斜體效果。此為預期行為，不在 `labMdxComponents` 另做樣式或載入 italic 字型。

This sentence mixes **bold**, _italic_, and `inline code` in one line.

| MDX | HTML | Styles | Notes |
| --- | --- | --- | --- |
| `**text**` | `strong` | _尚未 map_ | 瀏覽器預設；可切換至 GlowSans 800 |
| `*text*` | `em` | _尚未 map_ | 視覺上與正文相同（見上方說明） |
| `` `code` `` | `code` | `rounded bg-bg-card px-1.5 py-0.5 font-mono text-sm text-ash-100` | — |

```md
This sentence mixes **bold**, _italic_, and `inline code` in one line.
```

## Links（連結）

站內連結維持同頁導覽；外部連結（`http` 開頭）應開新分頁並帶 `rel="noreferrer"`。

Internal: [Back to Lab](/lab). External: [MDX docs](https://mdxjs.com/).

| MDX | HTML | Styles |
| --- | --- | --- |
| `[text](url)` | `a` | `text-accent underline-offset-4 hover:underline` |

```md
Internal: [Back to Lab](/lab). External: [MDX docs](https://mdxjs.com/).
```

## Lists（列表）

無序與有序列表，用於步驟或要點條列。

Unordered:

- First item
- Second item
- Third item

Ordered:

1. Step one
2. Step two
3. Step three

| MDX | HTML | Styles |
| --- | --- | --- |
| `-` / `*` | `ul` > `li` | `ul`: `mb-4 list-disc space-y-2 pl-6 text-text-secondary` · `li`: `leading-relaxed [&>ul]:mt-2 [&>ol]:mt-2` |
| `1.` | `ol` > `li` | `ol`: `mb-4 list-decimal space-y-2 pl-6 text-text-secondary` · `li`: 同上 |

```md
- First item
- Second item

1. Step one
2. Step two
```

### Nesting（巢狀列表）

巢狀列表透過縮排建立層級；子列表與上一級項目文字之間由 `li` 的上邊距拉開。

- Parent item
  - Nested unordered
  - Another nested item
- Sibling item

1. First step
   1. Nested ordered
   2. Another nested step
2. Second step

| MDX | HTML | Styles |
| --- | --- | --- |
| 縮排的 `-` / `1.` | `ul` / `ol` > `li`（巢狀） | 同 Lists · 父項與子列表間距：`li` 的 `[&>ul]:mt-2` / `[&>ol]:mt-2` |

```md
- Parent item
  - Nested unordered
  - Another nested item

1. First step
   1. Nested ordered
   2. Another nested step
```

