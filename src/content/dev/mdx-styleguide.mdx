# MDX Style Guide

Lab MDX 元素對照速查。\
**Maps to:** 為實際渲染的 HTML 標籤；\
**Styles:** 為 `labMdxComponents`（`mdx-components.tsx`）中的主要 class。內文繼承 `font-body`（GlowSans 單字型）；`type-page-title`、`type-section-title`、`type-nav`、`type-btn` 使用 `font-display` 混排（Montserrat Alternates + GlowSans）。`font-extrabold` 時混排層西文為 Montserrat 700、中文為 GlowSans 800。頁面 `<h1>` 由 MDX 的 `#` 提供（`type-page-title`）；正式 Lab MDX 應只寫一個 `#`。本 styleguide 在 h1 示範區可能刻意出現多個 `#`。

## Headings（標題）

MDX 的 `#` 為頁面標題（`h1`）；`##`、`###`、`####` 依序對應 `h2`、`h3`、`h4`。捲至 `## Paragraphs` 可見連續 `##` 的 `not-first:mt-12` 間距。

# Page title example

**Maps to:** `#` → `<h1>`\
**Styles:** `type-page-title mb-6 text-text-primary`

Lab MDX 頁面標題；正式作品 MDX 通常全檔只有一個 `#`（本頁頂部 `# MDX Style Guide` 即為此角色）。

## Section title example

**Maps to:** `##` → `<h2>`\
**Styles:** `type-section-title mb-5 text-text-primary not-first:mt-12`

Used for sections within an article.

### Subsection example

**Maps to:** `###` → `<h3>`\
**Styles:** `mt-10 mb-4 text-[1.5rem] leading-tight font-extrabold tracking-tight text-text-primary`

Used for finer-grained grouping.

```md
# Page title（maps to h1）

## Section title（maps to h2）

### Sub-subsection title（maps to h3）
```

### Mixed script headings（混排標題）

h1 層雙字型混排測試（刻意多個 `#` 示範）。西文 Montserrat Alternates，中文 GlowSans。

## Paragraphs（段落）

**Maps to:** `p`\
**Styles:** `mb-2 text-[1rem] leading-[1.75] text-text-secondary`

一般段落用於正文內容。內文走 `font-body`（GlowSans 單字型），英文使用 GlowSans 內建拉丁字母。

This is a sample paragraph. It uses secondary text color and `leading-[1.75]` line height for comfortable reading.

這是內文層範例：UI/UX Designer 專注於 Experience 體驗設計。

```md
This is a sample paragraph. It uses secondary text color and `leading-[1.75]` line height for comfortable reading.
```

## Text formatting（文字格式）

**Maps to:** `strong` / `em` / `code`\
**Styles:** `strong` / `em` 尚未 map；`code` 見下方

行內文字格式對照。`strong` 與 `em` 目前使用瀏覽器預設樣式，尚未在 `labMdxComponents` 自訂。

**Italic（`em`）刻意不處理：** 本站以中文內容為主，排版上不依賴斜體強調；GlowSans 僅載入 `font-style: normal` 字重，且 `body` 設有 `font-synthesis: none`，即使 MDX 寫 `*italic*` 渲染為 `<em>` 也幾乎看不出斜體效果。此為預期行為，不在 `labMdxComponents` 另做樣式或載入 italic 字型。

| Style       | Syntax       | Output        | Notes                          |
| ----------- | ------------ | ------------- | ------------------------------ |
| Bold        | `**text**`   | **Bold text** | 瀏覽器預設；可切換至 GlowSans 800 |
| Italic      | `*text*`     | _Italic text_ | 視覺上與正文相同（見上）         |
| Inline code | `` `code` `` | `inline code` | 見 `code` map                  |

This sentence mixes **bold**, _italic_, and `inline code` in one line.

```md
This sentence mixes **bold**, _italic_, and `inline code` in one line.
```

## Links（連結）

**Maps to:** `a`\
**Styles:** `text-accent underline-offset-4 hover:underline`

站內連結維持同頁導覽；外部連結（`http` 開頭）應開新分頁並帶 `rel="noreferrer"`。

Internal: [Back to Lab](/lab). External: [MDX docs](https://mdxjs.com/).

```md
Internal: [Back to Lab](/lab). External: [MDX docs](https://mdxjs.com/).
```

## Lists（列表）

**Maps to:** `ul` / `ol` / `li`\
**Styles:** `mb-4 list-disc space-y-2 pl-6 text-text-secondary` / `mb-4 list-decimal space-y-2 pl-6 text-text-secondary` · `li`: `leading-relaxed [&>ul]:mt-2 [&>ol]:mt-2`

無序與有序列表，用於步驟或要點條列。

Unordered:

- First item
- Second item
- Third item

Ordered:

1. Step one
2. Step two
3. Step three

```md
- First item
- Second item

1. Step one
2. Step two
```

### Nesting（巢狀列表）

**Maps to:** `ul` / `ol` / `li`（巢狀）\
**Styles:** 同上 · 父項與子列表間距：`li` 的 `[&>ul]:mt-2` / `[&>ol]:mt-2`

巢狀列表透過縮排建立層級；子列表與上一級項目文字之間由 `li` 的上邊距拉開。

- Parent item
  - Nested unordered
  - Another nested item
- Sibling item

1. First step
   1. Nested ordered
   2. Another nested step
2. Second step

```md
- Parent item
  - Nested unordered
  - Another nested item

1. First step
   1. Nested ordered
   2. Another nested step
```

### Code blocks（程式碼區塊）

**Maps to:** `figure` > `pre` > `code`\
**Styles:** `figure`: `mb-6 overflow-hidden rounded-xl border border-border-default bg-bg-card` · `pre`: `overflow-x-auto p-4 font-mono text-sm leading-relaxed` · 語法色由 `rehype-pretty-code`（`github-dark`）在 build time 產生

Fenced block with language tag（e.g. `js`）for syntax highlighting；無標籤時 fallback 為 `plaintext`。

```js
// pre wraps code; rounded corners, border, horizontal scroll
const phase = t * 0.001 + index * 1.2;
drawGradient(ctx, phase);
```

## Tables（表格）

**Maps to:** `table` / `thead` / `th` / `td`\
**Styles:** wrapper `mb-6 overflow-x-auto` · `table`: `w-full border-collapse text-sm` · `thead`: `bg-bg-card` · `th`: `border border-border-default px-3 py-2 text-left font-extrabold text-text-primary` · `td`: `border border-border-default px-3 py-2 text-text-secondary`

經典格線表：外層可橫向捲動；儲存格邊框、表頭加粗與 `bg-bg-card` 底色區分，配色使用 ash 語意 token。

| ------ | ----------- |
| `#`    | → `<h1>`    |
| `p`    | body text   |
| `th`   | header cell |
