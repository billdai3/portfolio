# Headings（標題）

**Maps to:** `#` → `h2` · **Styles:** `type-section-title mb-6 text-text-primary not-first:mt-12`

Lab 頁面大標由 layout 提供（`h1`）；MDX 的 `#` 渲染為 section 標題（`h2`）。`##`、`###` 依序對應 `h3`、`h4`。

The heading levels below are live examples. Scroll to the next `#` section (Paragraphs) to see `not-first:mt-12` spacing between consecutive `#` blocks.

## Section title example

**Maps to:** `##` → `h3` · **Styles:** `mt-10 mb-4 text-xl font-extrabold tracking-tight`

Used for subsections within an article.

### Subsection example

**Maps to:** `###` → `h4` · **Styles:** `mt-8 mb-3 text-lg font-extrabold`

Used for finer-grained grouping.

```md
# Section title（maps to h2）

## Subsection title（maps to h3）

### Sub-subsection title（maps to h4）
```
