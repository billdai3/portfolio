# 關於這個實驗

Color Waves 是一個用 **Canvas 2D** 畫出多層 radial gradient 的簡單範例，模擬之後從 CodePen 搬過來的互動作品會怎麼掛在左側展示區。

## 實作重點

- 使用 `requestAnimationFrame` 驅動動畫迴圈
- `ResizeObserver` 讓 canvas 跟著 sticky 面板縮放
- 品牌色 `#fcc92c` 與站內 ash 色系搭配

## 之後可擴充

1. 把 p5.js sketch 封裝在 `components/sketches/` 下
2. 在 MDX 裡 import sketch 做「文章內的小型互動」
3. 用 Leva 做 dev 時的參數面板（站內已有 GSAP + Leva 範例可參考）

> 左側 sketch 在 MDX 頂部透過 `createLabPage` 指定；正文用 Markdown 撰寫即可。
